# Code of Conduct

We welcome respectful, technical contributions from people with different experience levels. Discuss ideas and code rather than personal attributes. Harassment, threats, and disclosure of private credentials or personal data are not acceptable.

Maintainers may edit, close or remove abusive content and restrict participation. Report conduct concerns privately to the repository maintainer. For security vulnerabilities, follow SECURITY.md rather than opening a public issue.

This project emphasizes truthful test evidence, reproducible bug reports, responsible disclosure and least-privileged operation.
