# Changelog

## v1.0.0-rc3 — source release candidate, 2026-11-04

- Verified OAuth owner authorization with durable delegation and rolling grants.
- Owner file create/read/patch/delete operations with SHA-256, backup and audit.
- Opt-in OWNER_GLOBAL_FILESYSTEM across normal Windows drives subject to process account rights.
- Local backend, MCP gateway, desktop tools, watchdog and cloud adapter.
- Portable example configuration files and a separate clean source-release preparation process.

**Publication status:** not released publicly until security, install and history gates pass. Historical personal tunnel configs and artifacts require a clean history strategy.
